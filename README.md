# THE URBAN REALITY

Кинематографиялық сайт-презентация: «Основные проблемы города: стоимость жизни, проблемы жилья, транспорта. Проблема урбанизации населения».

## Іске қосу (презентация алдында)

```bash
npm install        # бір рет қана
npm run build      # сайтты жинау
npm start          # http://localhost:3000 ашылады
```

Сайт интернетсіз де жұмыс істейді. Медиа репозиторийде бір рет сақталған — `docs/assets/`; `npm run dev` / `npm run build` оны `public/assets/` ішіне өзі көшіреді. Тек қаріптер `npm run build` кезінде бір рет интернеттен жүктеледі.

## Презентация кезінде

| Әрекет | Қалай |
|---|---|
| Бастау (дыбыспен) | «НАЧАТЬ ПУТЕШЕСТВИЕ» |
| Ашылу сахнасын өткізіп жіберу | «ПРОПУСТИТЬ →» |
| Толық экран + презентация режимі | жоғарғы оң жақтағы ⤢ батырмасы |
| Келесі / алдыңғы тарау | → / ← (немесе PageDown / PageUp) — тек презентация режимінде |
| Дыбысты өшіру / қосу | M (презентация режимінде) немесе жоғарғы оң жақтағы дыбыс батырмасы |
| Шығу | Esc |

## Құрылым

- `components/chapters/` — 8 тарау + дереккөздер бөлімі
- `lib/data.ts` — барлық статистика және дереккөздер (мәні, жылы, сілтемесі)
- `ASSET_SOURCES.md` — әр фото, видео, музыканың авторы мен лицензиясы
